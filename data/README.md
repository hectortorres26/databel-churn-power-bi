# Datos originales

El escenario ficticio y los datos pertenecen al caso educativo [Case Study: Analyzing Customer Churn in Power BI](https://app.datacamp.com/learn/courses/case-study-analyzing-customer-churn-in-power-bi) de DataCamp.

El enlace «Exercises and Datasets» de la página del caso lleva al paquete original. El CSV se encuentra en `Datasets/Databel - Data.csv`. Para repetir la auditoría, coloca una copia en esta carpeta con ese nombre y ejecuta `python scripts/analizar.py` desde la raíz.

La plantilla permite usar el CSV público referenciado por el modelo inicial de DataCamp o una ruta local mediante el parámetro `FuenteCSV`. Si la URL deja de funcionar, obtén el archivo desde el curso y sustituye el parámetro. No se presupone disponibilidad perpetua del recurso.

El archivo utilizado contiene 6 687 clientes y 29 columnas. SHA-256: `f66d6dbae9dd024edf4c775c6201eac07ef197067001963214531767584cb77e`. El CSV del paquete y el del enlace público coincidieron byte a byte en esta revisión.

No redistribuyo el CSV ni los PBIX oficiales en este repositorio. El código, las agregaciones y la plantilla documentan la adaptación; no se atribuye una licencia abierta a los materiales de terceros.
